# Планировщик задач (TODO-лист)

## Описание проекта

Веб-сервер для управления задачами с поддержкой правил повторения. Реализован на языке Go с использованием стандартной библиотеки `net/http` и базы данных SQLite.

Проект создан в рамках дипломной работы курса Go-разработчика.
Приложение позволяет создавать, редактировать, удалять задачи, отмечать их как выполненные и настраивать правила повторения (ежедневно, еженедельно, ежемесячно, ежегодно).

##  Выполненные задания со звёздочкой
- **Шаг 1** — определение порта сервера через переменную окружения `TODO_PORT`.
- **Шаг 2** — определение пути к файлу базы данных через переменную окружения `TODO_DBFILE`.
- **Шаг 3** — реализована полная поддержка всех правил повторения, включая правила для дней недели (`w 1,4,5`) и дней месяца (`m 1,15,-1`).
- **Шаг 5** — реализован поиск задач по заголовку/комментарию и по дате через параметр `search` в запросе `/api/tasks`.

**Не выполнено:**
- **Шаг 8** — аутентификация пользователей (опциональный шаг, не реализован).
